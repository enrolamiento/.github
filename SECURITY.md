# Seguridad

## Reportar una vulnerabilidad

Si encontró una vulnerabilidad en la API de Enrolamiento, en sus sitios o en el código de esta
organización, escriba a **soporte@enrolamiento.cl** con el asunto «Seguridad». No la publique en un
issue, una discusión ni un pull request.

Incluya, en lo posible:

- qué encontró y qué permite hacer;
- los pasos para reproducirlo;
- la dirección, la operación o el archivo afectado.

No incluya credenciales reales, certificados ni datos de contribuyentes en el reporte. Si su APIKey
quedó expuesta, cámbiela de inmediato en el portal de clientes: **Mi Cuenta**, pestaña
**Integración**.
