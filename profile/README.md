# Enrolamiento

La certificación SII para emisores de DTE, en una API. Enrolamiento automatiza la certificación
obligatoria ante el Servicio de Impuestos Internos de Chile, la administración de folios (CAF) y la
portabilidad desde el portal MiPyme, para que los proveedores de software enrolen a sus empresas sin
hacer el trámite a mano.

## Empezar

1. Cree su cuenta en [www.enrolamiento.cl](https://www.enrolamiento.cl).
2. Siga el [Quickstart](https://developers.enrolamiento.cl/docs/quickstart/): de las credenciales a la primera respuesta.
3. Clone los [ejemplos](https://github.com/enrolamiento/examples) y adáptelos a su sistema.
